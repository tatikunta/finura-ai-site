Canonical detail lives in the ECRP repo: docs/architecture/ai-ml-architecture.md (agentic core, ML risk, feature flags, Cloud Run path). This page is the public summary for enterprise buyers.

Agentic core

LangGraph-style stage orchestration behind flags; LiteLLM / Gemini for generation; LlamaIndex + pgvector hooks for retrieval — all fail closed when flags are off.

Control plane

Scoped bearer tokens, CORS allow-list, rate limits, optional Turnstile, and production docs hiding when FINURA_ENV=production.
